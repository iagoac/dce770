# Segunda etapa do trabalho final

Nesta etapa cada aluno deverá trabalhar com base no problema e artigo escolhido

Nesta etapa espera-se duas coisas:
- Definição de um conjunto de instâncias de teste
- Implementação de um ou mais algoritmos propostos no drtigo escolhido

As instâncias deverão ser criadas de acordo com o artigo escolhido. Deverão ser utilizadas, pelo menos, 50 instâncias de teste. Estas deverão ter tamanhos variados de forma a possibilitar a avaliação dos algoritmos propostos.

Já o algoritmo poderá ser desenvolvido em qualquer linguagem de programação, como C, C++, Java, ou Python, dentre outras.

O relatório da entrega passada deverá ser corrigido e aumentado. A segunda versão do relatório deverá conter, além das sessões anteriores, uma sessão explicando o algoritmo desenvolvido e outra detalhando o processo de criação das instâncias e o resumo de suas características.

## Entrega

A entrega deverá ser realizada pelo Moodle da disciplina até o dia 17/10 e deverá, necessariamente, utilizar o _template_ disponibilizado neste repositório.

Nesta etapa, deverão ser entregues:
- Relatório em formato _.pdf_
- Conjunto de instâncias criado

## Avaliação

Cada trabalho será avaliado de acordo com a qualidade e variedade das instâncias criadas, assim como pela nível de detalhamento do algoritmo implementado. Recomenda-se a utilização de pseudo-códigos (e não _prints_ do código desenvolvido). Não é necessário realizar a análise de complexidade dos algoritmos desenvolvidos, a não ser que isto seja extremamente relevante para o contexto de seu trabalho.

Neste segundo relatório, será avaliado:
- Qualidade geral da apresentação do problema
- Relevância dos trabalhos relacionados para o tema proposto
- Uso correto do _template_ LaTeX
- Uso correto do sistema de referências BibTex
- Detalhamento e reprodutibilidade do algoritmo descrito
- Detalhamento do algoritmo de criação das instâncias
