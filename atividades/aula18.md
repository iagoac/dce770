# Um algoritmo BRKGA para o problema do caminho mais longo

Seja o problema do caminho mais longo como definido no material anexo e disponível em [caminho_mais_longo.pdf](caminho_mais_longo.pdf). Para esta atividade (e para as demais), considere o caminho mais longo entre quaisquer par de vértices do grafo.

O objetivo desta atividade prática é desenvolver
 - Um algoritmo evolutivo para o problema do caminho mais longo. Mais especificamente, deverá ser implementado um algoritmo baseado no *framework* BRKGA desenvolvido em sala.

Existe um *framework* extremamente bem estabelecido na literatura para desenvolvimento de heurísticas baseadas em BRKGA. O código está disponível [neste repositório do GitHub](https://github.com/rfrancotoso/brkgaAPI) e é descrito [neste artigo](https://mauricio.resende.info/doc/brkgaAPI.pdf).

O código desenvolvido deve ser entregue no Moodle da disciplina até o dia **19/10/2026** às **09h59**. A entrega é **individual**.

---

## Orientações

Uma vez que o código disponibilizado já possui todos os operadores evolutivos do BRKGA implementados, deve-se implementar somente o algoritmo decodificador.
