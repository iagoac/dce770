# Segunda etapa do trabalho final

Nesta terceira etapa cada aluno deverá trabalhar com base no problema e artigo escolhido

A partir do pressuposto que vocês já tem o conjunto de instâncias de teste, nesta etapa espera-se:
- Implementação e avaliação do artigo base da literatura
- Proposição, implementação e avaliação de uma nova heurística/metaheurística para o problema proposto

Os algoritmos deverão avaliar um subconjunto das instâncias propostas somente como forma de avaliar sua correta implementação. O conjunto final de testes e avaliação será realizado na quarta etapa.

O relatório da entrega passada deverá ser corrigido e aumentado. A terceira versão do relatório deverá conter, além das sessões anteriores, uma sessão explicando o algoritmo proposto e outra exibindo os resultados dos experimentos computacionais realizados. Para isto, deve-se incluir também as características (modelo do processador, quantidade de RAM, sistema operacional, etc) do computador utilizado para testes.

## Entrega

A entrega deverá ser realizada pelo Moodle da disciplina até o dia 17/10 e deverá, necessariamente, utilizar o _template_ disponibilizado neste repositório.

Nesta etapa, deverão ser entregues:
- Relatório em formato _.pdf_
- Conjunto de instâncias utilizado (mesmo da segunda entrega)
- Algoritmos desenvolvidos (qualquer linguagem de programação)

## Avaliação

Cada trabalho será avaliado de acordo com a qualidade do algoritmo desenvolvido e pela qualidade dos resultados reportados. Espera-se que o algoritmo desenvolvido seja melhor que o da literatura para as instâncias avaliadas.

Neste terceiro relatório, será avaliado:
- Qualidade geral da apresentação do problema
- Relevância dos trabalhos relacionados para o tema proposto
- Uso correto do _template_ LaTeX
- Uso correto do sistema de referências BibTex
- Detalhamento e reprodutibilidade do algoritmo descrito
- Detalhamento do algoritmo de criação das instâncias
- Boa apresentação da nova heurística/metaheurística
- Qualidade de apresentação dos resultados
  - O uso de tabelas e gráficos é altamente recomendado
  - Deve-se avaliar tanto o resultado (valor de função objetivo) quanto o tempo de execução dos algoritmos
